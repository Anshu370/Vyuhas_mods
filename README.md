# Mahabharata Vyūha Warfare — Prototype 0.8.1 — Symmetric Vajravyūha geometry

Target: Minecraft Java 1.20.1, Forge 47.4.x, Java 17. Compatibility target: Villager Recruits 1.14.0.

This is a separate addon. It does not bundle, copy, or redistribute Recruits source. It uses reflection to request Recruits' native hold-position state. The upstream repository says “All Rights Reserved unless otherwise explicitly stated”; see https://github.com/talhanation/recruits.

## Commands
- `/vyuha preview line <count>` — visual preview (2–40 slots).
- `/vyuha form line <radius>` — the existing working line formation; radius is the recruit search radius.
- `/vyuha form vajra partial <radius>` — partial Vajravyūha deployment; missing category slots remain empty.
- `/vyuha form vajra full <radius>` — full deployment; requires the complete category roster and all 92 assigned stations to have safe ground.
- `/vyuha form vajra <radius>` — backward-compatible alias for partial deployment.
- `/vyuha release` — switches tracked soldiers to Recruits' native stationary Hold Position state at their current locations.

The `radius` argument (4–32) controls how far away the addon searches for commandable recruits. It does not change the Vajra footprint.

## Vajra fixed blueprint

- Main formation footprint: 64 × 64 blocks. Its 10-step diamond uses 3-block slot spacing, spanning approximately 60 × 60 blocks within the footprint. Each ring is sampled symmetrically; role slots are not generated by truncating one side of a ring.
- Template capacity: **92 troops**.
- Nomad: 8 heavy-unit stations, representing elephant/chariot positions.
- Horseman: 20 cavalry-wing stations.
- Shieldman: 20 outer infantry stations.
- Standard Recruit: 20 second-layer infantry stations.
- Bowman: 12 inner ranged stations.
- Crossbowman: 12 innermost ranged stations.

Full mode requires at least the listed number of each category. If a category is short, the command is cancelled before any soldiers are moved and reports the missing count. Additional troops beyond their category's slots are assigned to a square reserve behind the main diamond. Partial mode permits short categories; unused slots remain empty and are never filled with another category.

The full-mode terrain check validates all 92 formation stations for safe ground before deployment. It does not scan every block in the 64 × 64 bounding square for arbitrary hazards; the deployment should still be tested on a broad, flat, unobstructed area. Partial mode skips stations that do not have safe ground.

## Category detection

The addon attempts to classify roles using entity registry IDs and held equipment (bow, crossbow, shield). If Recruits 1.14.0 represents multiple table variants with one entity ID and does not expose the role through equipment, that category cannot be reliably inferred by this generic classifier. If the role counts reported in-game are wrong, inspect the exact entity data in the installed Recruits version and add a version-specific adapter. Nomad classification currently relies on the entity ID containing `nomad`.

## Build and test
1. Extract this ZIP and upload/replace the project files in the existing GitHub repository, including `.github/workflows/build.yml`.
2. Run GitHub Actions workflow `Build Forge 1.20.1 mod`.
3. Download artifact `vyuha-warfare-jar`; remove the previous Vyūha Warfare JAR before installing the new one. Keep Recruits installed.
4. Test in a backed-up or Creative world on a broad, flat area. Ensure recruits are owned by you and listening for commands.
5. Test partial mode first: `/vyuha form vajra partial 16`.
6. For full mode, bring at least 8 Nomads, 20 Horsemen, 20 Shieldmen, 20 standard Recruits, 12 Bowmen and 12 Crossbowmen within 16 blocks, then run `/vyuha form vajra full 16`.
7. Run `/vyuha release` before testing another formation.

## Limitations
- This ZIP has not been compiled in this environment; use GitHub Actions to compile it. Version 0.8.1 specifically corrects asymmetric ring-slot selection that could create a cross-like pattern instead of a continuous diamond.
- Terrain checking validates target stations but does not pathfind around obstacles.
- Combat AI can temporarily pull soldiers away from their positions.
- Role classification needs in-game verification against Recruits 1.14.0.
